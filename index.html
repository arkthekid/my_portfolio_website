Threads App

Project 1 (Independent Project)

This is a Threads clone app I developed using TypeScript and Next.js. My idea was to create a platform that mirrors the core features of a modern social media site that focuses on thread creation and user interactions, profile management, and real-time updates, making each user's experience dynamic and engaging. For the backend, I used MongoDB to implement reliable data storage for everyone. Security was a top priority, so I implemented secure user authentication using Clerk to keep user data safe. The interface is built with Next.js and uses server-side rendering for efficient data fetching and smooth updates. I aimed to provide a fully responsive, modern full-stack web application, so Vercel was used for deployment to ensure reliable performance for users. Converso

Project 2 (Independent Project)

Converso is a SaaS-style AI learning platform built with TypeScript and Next.js that allows users to create personalized AI learning companions. Like a true SaaS product, it lets users securely sign in, create and manage their own data, and access their learning tools from anywhere, all delivered through a scalable, cloud-based architecture. Each companion can have its own name, subject, personality, and teaching style, with lessons and conversations generated dynamically through the OpenAI API. The backend uses Supabase (PostgreSQL) to manage companions, sessions, and bookmarks through relational schemas, while Clerk provides secure authentication, user management, and protected routes. The UI is built with Next.js App Router, TailwindCSS, and Shadcn UI to deliver a fast, responsive, and modern experience, with React Hook Form and Zod ensuring reliable form validation. Deployed on Vercel, Converso demonstrates my ability to build a full end-to-end SaaS application—from multi-user authentication and database design to AI integration, UX design, and production deployment.

Tic-Tac-Toe Game

Project 3 (Independent Project)

This is a Tic-Tac-Toe game I coded using Python. I wanted to create a program with a smooth user interface and a bot that would be challenging to beat. You can play against three types of opponents: another player, an easy bot, and a hard bot. The easy bot randomizes its moves, while the hard bot uses the minimax algorithm to find the best possible move. This algorithm is a recursive search that simulates every possible move. On the bot's turn, it chooses the move with the highest score, and on your simulated turn, it chooses the move with the lowest score. The user interface was built using PyQt5.
